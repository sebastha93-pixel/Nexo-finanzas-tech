Tu información sensible, blindada

Manejamos datos financieros, así que la seguridad no es opcional. ORIA está construida con protección de extremo a extremo:

  • Cifrado de datos en tránsito y de los tokens de acceso.
  • Solo lectura de tus correos: ORIA nunca envía, modifica ni borra correos.
  • Nunca accedemos a tus contraseñas bancarias ni movemos tu dinero.
  • Aislamiento de datos por usuario a nivel de base de datos.
  • Desbloqueo biométrico (Face ID / huella) en la app.
  • Nunca vendemos tus datos ni los usamos para publicidad.

Cómo usamos el acceso a Gmail

ORIA solicita el permiso gmail.readonly únicamente para leer los correos de alerta transaccional que tu banco envía a tu Gmail, con el fin de extraer el monto, la fecha, el comercio y el tipo de cada movimiento y registrarlos automáticamente en la app. El acceso es de solo lectura y aplicamos filtros para procesar exclusivamente esos correos de alerta bancaria.

El uso que ORIA hace de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado. No usamos estos datos para publicidad y no los vendemos ni los transferimos a terceros salvo lo estrictamente necesario para prestar el servicio, cumplir la ley o con tu consentimiento.

Puedes desconectar Gmail o eliminar tu cuenta y todos tus datos cuando quieras.
